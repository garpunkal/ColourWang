# Client (ColourWang)

This folder contains the React + Vite frontend for ColourWang.

For full project setup, architecture, and multiplayer run instructions, use the root README:

- `../README.md`

## Client Scripts

Run from this folder:

- `npm run dev` - start Vite dev server
- `npm run build` - type-check/build + Vite production build
- `npm run preview` - preview production build
- `npm run lint` - run ESLint

## Notes

- Local development uses HTTPS.
- Certificates are generated into the repo-level `certs` folder.
- If mobile devices cannot connect, run from the project root (`npm run dev`) and use your LAN IP URL.
